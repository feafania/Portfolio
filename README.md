# Portfolio – Tatsiana Kashko

A modern, responsive personal portfolio website built with **HTML5** and **SCSS**. The website showcases my skills, projects, work experience, and contact information while following modern web development best practices, including accessibility, responsive design, and clean architecture.

## ✨ Features

- Responsive mobile-first layout
- Modern and clean UI
- Accessible navigation
- Semantic HTML5 markup
- Modular SCSS architecture
- Interactive portfolio section
- About Me section
- Contact form
- Smooth scrolling navigation
- Cross-browser compatibility

## 🛠️ Technologies

- HTML5
- SCSS (Sass)
- CSS Flexbox
- CSS Grid
- BEM Methodology
- Git
- GitHub Pages

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/feafania/Portfolio.git
```

Navigate to the project folder:

```bash
cd Portfolio
```

Install Sass (if not already installed):

```bash
npm install -g sass
```

Compile SCSS:

```bash
sass --watch sass:css
```

Open `index.html` in your browser.
